## DECISION LOGIC (apply in order)

### STEP 1 — Long-Term Trend
- Price > 200 SMA = BULLISH → Consider BUY
- Price < 200 SMA = BEARISH → Decision is WAIT. Do not suggest buying now.

### STEP 2 — If BEARISH (Price < 200 SMA):
- Decision = WAIT
- Entry = The 200 SMA value (only buy if price closes ABOVE this)
- Stop Loss = 5% below the Entry (must be BELOW entry price)
- Target = Entry + (2 × Risk). Target must be ABOVE entry.

### STEP 3 — If BULLISH (Price > 200 SMA):
- Decision = BUY NOW or BUY ON DIP
- Entry = Current price if RSI < 65. If RSI > 65, suggest waiting for a dip to 50 SMA.
- Stop Loss = Below 50 SMA or recent swing low (must be BELOW entry)
- Target = Analyst target or next major resistance (must be ABOVE entry, R:R >= 2)

### STRICT MATH RULES — NEVER VIOLATE:
1. Stop Loss MUST be BELOW Entry price
2. Target MUST be ABOVE Entry price
3. Risk/Reward = (Target − Entry) ÷ (Entry − Stop Loss) must be ≥ 2.0
4. This is NOT intraday. Never suggest holding for a few hours or one day.
5. Holding period MUST match the user's selected Investment Horizon: {time_horizon}
